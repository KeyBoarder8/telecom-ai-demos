# Telecom AI Demos

中国电信新区 AI 智慧服务演示平台，包含企业知识中枢、智能问答、智能客服、检修工单、智能质检和运营驾驶舱。

> 本项目为 DEMO/POC，页面中的客户、人员、号码、工单和经营指标均为模拟或脱敏数据，不代表真实生产经营情况。

## 已实现能力

- 企业知识空间、文档列表和文档搜索
- 多模态智能问答与来源引用
- LOS 告警识别和专线故障模拟诊断
- 客服会话、客户画像、情绪与风险提示
- P1 检修工单创建、智能派发和 SLA 展示
- 专员受理、检修结果回写、客户确认和归档
- 工作流 Trace ID 与处理时间轴
- 智能质检、风险会话和运营图表
- 响应式页面与断网可用的 Mock 演示数据

## 主演示链路

```text
客户报障
→ 上传告警截图
→ 多模态识别与知识检索
→ 模拟网管诊断
→ 创建 P1 检修工单
→ 智能派发与邮件通知
→ 专员受理和结果回写
→ 客户确认
→ 工单归档
```

## 本地运行

环境要求：Node.js 20.19 或更高版本。

```bash
npm install
npm run dev
```

默认访问地址：<http://localhost:5173/>

## 构建与检查

```bash
npm run lint
npm run build
```

## 项目结构

当前版本采用 Vue 3、TypeScript、Vite 和 ECharts，是可交互前端演示。CRM、综合网管、邮件和大模型调用采用 Mock 数据。生产接入应通过后端适配层完成，并遵循权限、脱敏、审计和幂等要求。
